# Agent Instructions — Context & Search Rules

## node_modules Policy
- **NEVER** read, search, or traverse inside `node_modules/` directories unless explicitly instructed to do so.
- **NEVER** include `node_modules/` in `grep`, `glob`, or `read` operations.
- If you need to check a package version or API, read `package.json` instead.
- `node_modules/` should be treated as invisible in all file listings and searches.

## When to touch node_modules
Only if the user explicitly says something like:
- "Install package X"
- "Check what version of Y is installed"
- "Look inside node_modules/package-name for..."

**If you ever feel you need to read node_modules, ask the user first and clarify why you need it.** Do not do it unprompted.

Otherwise, it does not exist in our context.
