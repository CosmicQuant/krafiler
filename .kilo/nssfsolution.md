Root cause identified: When you click OK on the "Payment Order was successfully saved" dialog, NSSF server sends a POST response to paymentOrder.xhtml with Content-Type: application/pdf and ~82KB of actual PDF bytes. Chrome opens this in a new window using its built-in PDF viewer.
Solution: We intercept the network response using Playwright's context.route('**/secureAdmin/paymentOrder.xhtml', ...) before clicking OK. The route handler captures the raw response body, verifies it starts with %PDF, and writes it directly to disk. No HTML rendering, no screenshots, no blob extraction needed.
