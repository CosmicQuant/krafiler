   - Decrypt in worker before Playwright login
   - **Files:** `clients.firestore.ts`, `tax.routes.ts`, worker HTTP handler

2. **Remove `.archive/` directory**
   - Simple cleanup; delete folder and update `.gitignore`

3. **Switch to separate Cloud Run worker service**
   - Create `krafiler-worker` service with `--concurrency 1 --max-instances 1 --memory 4Gi`
   - Single service currently handles REST + worker; this is a scalability risk

4. **Per-user Cloud Tasks queues**
   - Currently all users share `krafiler-filing-queue`
   - Queue should be created per user on first payment
